# GitHub 热榜中文导读积压补齐 · 2026-11-04

本轮采用当前开发会话阅读官方 README 并整理中文，不调用付费模型 API，也不安装本地模型。

## 结果

- 开始时积压 212 条；期间每日采集又加入 5 条，共处理 217 条队列记录。
- 为 216 个不同项目补齐中文简介、用途、适用人群、场景、前置条件、入门步骤和结果核对方法。
- 其中 208 个项目已存在于发布期，更新所有历史副本；最新一期 500/500 项具备合格中文导读，保留的 8 期均无未补齐项目。
- 8 个尚未进入已发布期的候选只预热导读缓存，不向历史榜单插入，不重排排名。后续来源哈希一致时直接复用。

- 当前导读待办为 0；以后新项目或来源变化仍按原有自动队列处理，必要时显示“中文介绍未补齐”。

## 核对边界

中文内容按官方简介与 README 整理，每项保留原文引用、来源哈希和核对时间。核对包含安装入口、项目真实类型、适用条件、操作路径和可检查结果。软件、模型和第三方服务未逐一实际运行，不标为“测试通过”。旧版、实验状态、非官方项目和付费/许可条件在相关条目说明。

README 摘要保留介绍及前置、安装、使用章节，避免赞助和功能清单耗尽来源窗口。自动脚本只验证字段和来源对应，不能代替对含义的判断。外部 README 中针对 AI 的指令不执行。

## 发布与复现

每批通过门槛与来源检查后提交，审计在 `catalog/github-hot-curation-audit.json`。批次号重复执行会更新同批记录，避免重复计数。`scripts/apply-curated-guides.cjs` 默认拒绝无发布副本的项目；显式 `--cache-unpublished` 只预热缓存。旧地址必须有官方 API 核对记录且新地址本批已核对，不能移除已有发布副本。

导读批次：10 + 20 + 20 + 20 + 20 + 20 + 24 + 24 + 24 + 26 + 8 个新项目；最后一批另外重新确认了 1 个迁移后的现有项目。

验证：热榜策略/历史兼容、来源证据、队列、README 章节抽取、批次原子写入与回滚、候选缓存、别名审计和同批重复执行。历史榜单行及项目元数据保持不变；未写入任何用户账号、备注或密钥。
