# 精选 Skill 目录

为 Cockpit 签到助手维护中文精选目录、分类、用途、使用方法、来源、许可和依赖说明。

首批 24 条：设计 12、办公 6、开发 6。包含平面设计、UI 设计、3D 设计、商业修图、日常办公及软件开发。标准 Skill 与提示词模板分别标注。

## 更新目录

编辑 catalog/skills.json，保持 schemaVersion 为 1、条目 id 稳定且唯一，并更新 updatedAt。标准 Skill 来源固定到完整 GitHub 提交 SHA，保留来源路径与许可证信息。新增资源需核对用途、依赖及许可；未确认下载许可的条目仅提供来源入口。

客户端每日检查一次，可手动刷新；更新失败保留本地缓存。目录修改无需重新发布客户端。

个人 Skill、账号凭据、设备标识、日志、截图和用户文件仅保存在本机，不上传到此仓库。

## 使用与许可

条目详情列出所需软件、MCP 或配套资源。上游资源保留各自许可证；来源核验不代表已在所有环境实测。用户可通过助手查看说明、复制提示词或下载许可允许的完整资源副本。
