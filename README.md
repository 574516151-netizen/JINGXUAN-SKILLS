用于 Cockpit 助手的可更新目录。只考虑免费运行路径，逐条真实任务通过后才加入“免费实测精选”。

当前共 72 条：**0 条免费实测精选、53 条待实测候选、19 条未纳入免费范围**。已尝试 1 条真实执行（5 个案例，4 通过、1 失败），故仍为候选；另外 52 条可测试候选尚未执行。此目录不是实时热门榜，也不宣称全部条目经过效果实测。

图片压缩的混合批次测试发现损坏图片未被正确报告，详见 [实测报告](reports/image-compression.md)。本机以 Node/esbuild/Sharp 执行经转换的原始 TypeScript，未验证 Bun 原启动路径；简易测试图的压缩率不能视为通用性能结论。
