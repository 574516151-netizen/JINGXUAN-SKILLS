# 精选 Skill 目录

Cockpit 助手的可更新资源目录，按用途、文档完整性、维护情况、来源关注度与许可证整理。提供中文用途、使用方法、示例提示词与依赖说明。

当前共 73 条、18 个分类：精选资源 54 条，免费条件待确认 19 条。保留免费范围要求，依赖收费 API 或长期免费情况不明确的资源单独展示。仓库 Star 只代表来源关注度，不代表单条 Skill 的使用量、下载量或质量保证。

[目录 JSON](catalog/skills.json) · [收录及更新规则](SELECTION-POLICY.md)

下载和加入个人库保留完整文件结构及许可证；复制权限未明确或受限制的资源会禁用按钮并说明原因。个人库保存在用户本机，目录更新不会覆盖或删除个人副本、收藏和已导出文件。

客户端每天检查一次，可手动检查更新。来源更新时重新核对完整配套和使用说明；这里是分类目录，不是实时热门榜。发布前运行 `node scripts/validate-catalog.cjs` 验证格式、固定来源版本和许可证链接。

新增“图片转可编辑分层 PSD”（weaiw/design-to-psd，MIT），位于平面设计、图像处理与 UI 设计。一个 Skill 附完整脚本、图层规范及安装配套；支持文字对象写入，复杂插画通常为独立位图层。用途、安装使用、调用示例及结果检查已整理；不宣称一键恢复原始设计源文件。当前客户端可在 Skill 管理中手动检查更新获取条目。
