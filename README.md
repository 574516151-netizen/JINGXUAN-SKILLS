## 怎样精选，热度代表什么

目录按明确用途、来源、维护状态、Skill 文件结构、配套依赖及许可整理。优先参考关注度较高的来源，也保留解决特定用途的社区补充条目；低关注度资源不伪装成热门。

本次来源核验时间：**2026-10-06**。每个标准 Skill 的 popularity 记录 GitHub **来源仓库**的 Star / Fork 及统计时间；这是公开关注度快照，不是单条 Skill 的使用量、浏览量、下载量，也不是效果评分。没有公开指标时不编造。

每条记录的 review 说明核验范围与入选理由，maintenance 标注上游仓库最近推送时间。此次核对来源、YAML 头部、目录结构、文件数量 / 体积与许可证；**未执行全部 Skill、收费生成 API 或外部自动化工作流**。精选目录不声称所有条目已实测好用。

## 使用与许可

先看详情中的软件、MCP、配套 Skills、鉴权及费用前置条件。文件管理和复制提示词不会自动增加模型、插件或生成能力。

标准 Skill 的来源固定到完整 GitHub 提交 SHA，保留原始文件结构及许可证。MIT / Apache-2.0 等已确认复制许可的条目可下载；未发现明确许可或条款限制复制的条目仅提供来源入口。Remotion 等软件的运行与商业使用条件需按上游说明另行确认。

中文展示信息与原始 Skill 内容分开保存。上游许可归各原作者所有；助手自制的商业修图需求提示词模板按其条目记录的 CC0-1.0 提供。

## 更新目录

编辑 [catalog/skills.json](catalog/skills.json)，保持 schemaVersion 为 1、条目 ID 稳定且唯一，并更新 updatedAt。新增资源需核对用途、结构、来源提交、依赖与许可。关注度数据应附来源和采集时间，不能使用单个仓库的 Star 推断每条 Skill 的下载量。

新版客户端内置离线目录，每日检查一次，可手动刷新；失败保留缓存。目录更新无需重新发布客户端。旧客户端如缺少新分类与排序，请使用包含扩展分类的版本。

个人 Skill、账号凭据、密钥、设备标识、日志、截图与用户文件不存放在此仓库。
